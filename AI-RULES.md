# AI-RULES — как не сделать «сайт от нейронки»

Правила для каждого сайта этого проекта. Источники: наш премиум-стандарт, разбор видео Metics Media, советы Германа Шарнина (как подсказки, а не догма).

## 1. Первый экран
- Один огромный заголовок, одна короткая строка, одна кнопка. Больше ничего.
- Никаких мелких подписей над заголовком, бейджей, «★ 4.9», «New», эмодзи, чипов, лишних пометок.
- Визуал первого экрана иллюстрирует смысл заголовка, а не просто «красивый фон».

## 2. Текст
- Абзацы — 1–2 короткие строки. Конкретика вместо общих слов («гарантия 2 года», а не «высокое качество»).
- Запрещены AI-штампы: «откройте для себя», «мы предлагаем широкий спектр», «индивидуальный подход к каждому клиенту», «ваш надёжный партнёр», «инновационные решения».
- Без капслока в абзацах, без восклицательных знаков в маркетинге.

## 3. Визуальный язык
- Типографика — главный инструмент: крупные заголовки с характером, максимум 2 шрифта, только с кириллицей.
- Много воздуха. Отступы только из шкалы токенов, никаких «на глаз».
- Палитра ограничена токенами. Никаких дефолтных фиолетово-синих градиентов «как у всех AI-сайтов».
- Запрещены: стоковые 2D-иконки в кружочках, ряды из трёх одинаковых карточек с иконкой сверху как единственный приём, эмодзи вместо иконок, тени «по умолчанию».
- Единый приём (блик, стекло, свечение) повторяется по сайту — это и есть стиль.

## 4. Анимация
- Анимация ведёт взгляд и несёт смысл, а не «крутится ради красоты».
- Только transform и opacity (GPU), 60 fps на телефоне. Тяжёлые эффекты (backdrop-filter, большие blur) — дозированно.
- Никаких эффектов только по наведению мыши: всё, что есть на hover, работает по тапу или скроллу.
- Уважать `prefers-reduced-motion`.

## 5. Конверсия
- Одно главное действие, кнопка повторяется по ходу страницы.
- Кнопка видна издалека (проверка: отдалить макет).
- Формы — минимум обязательных полей (имя + телефон), понятные состояния фокуса/ошибки, маска телефона, плавающий лейбл, сообщение об успехе.
- Важное не прятать в слайдер на десктопе. Горизонтальный свайп — только на телефоне.

## 6. Контент
- Перед публикацией: реальные контакты, только реальные отзывы, все кнопки и ссылки работают.
- Демо-контент помечается в коде как заглушка.

## 7. Техника
- Мобильная версия — с первого дня, не «потом».
- Картинки: AVIF/WebP, адаптивные размеры, lazy-load ниже первого экрана, явные width/height.
- Техническое SEO: title/description, Open Graph, canonical, sitemap.xml, robots.txt, schema.org.
- Бесплатный стек: Eleventy, GSAP, Lenis, бесплатные шрифты, Netlify.
